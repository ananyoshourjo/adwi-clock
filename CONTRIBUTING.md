# Contributing

Thank you for wanting to make Adwi Clock a little nicer.

This app began as a small gift, so the guiding question is simple: **does this
make studying feel calmer, cuter, or kinder?**

## Set up the project

You will need a current Node.js LTS release and an Expo-compatible Android,
iOS, or web environment.

```sh
npm install
npm start
```

Before opening a pull request, run:

```sh
npm run check
```

## A few design promises

- Keep the stopwatch and timer easy to understand at a glance.
- Prefer soft, low-attention motion over bouncy or distracting animation.
- Weather should stay ambient; it is a background feeling, not another tab.
- Location must remain optional.
- Keep controls accessible and label interactive elements.
- Do not add tracking, advertising, or an account system.

Small pull requests are welcome. For a larger visual or behavioral change,
please open an issue first so nobody spends a weekend building in the wrong
direction.

By contributing code, you agree that it may be distributed under the MIT
License. Only submit artwork, audio, or fonts you have the right to share, and
describe their license in the pull request.
